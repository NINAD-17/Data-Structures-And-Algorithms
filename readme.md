# My DSA Practice

This repository is where I keep my C++ practice as I learn data structures and algorithms. I solve problems, try out implementations, and save notes so I can revisit what I have learned. It is a personal collection of practice solutions, organized by topic for easy reference.

The [problem index](questions.md) lists **390** practice files. Some folders also contain notes and implementation examples alongside problem solutions.

## Topics

- [Basic](%5B01%5D%20Basic/) — number-system conversions, input, types, and simple number problems.
- [Arrays](%5B02%5D%20Arrays/) — searching, sorting, duplicates, intervals, and subarray problems.
- [2D Arrays](%5B03%5D%202D%20Arrays/) — matrix traversal, transformations, and search.
- [Numbers](%5B04%5D%20Numbers/) — number properties, digits, primes, and arithmetic problems.
- [Strings](%5B05%5D%20Strings/) — character and string operations, matching, windows, and anagrams.
- [Maths For DSA](%5B06%5D%20Maths%20For%20DSA/) — primes, sieves, GCD/LCM, exponentiation, and Catalan numbers.
- [Pointers](%5B07%5D%20Pointers/) and [Memory Allocation](%5B08%5D%20Memory%20Allocation/) — pointers, references, and dynamic allocation.
- [Extra Topics of C++](%5B09%5D%20Extra%20Topics%20of%20C%2B%2B/) — macros, inline functions, global variables, and default arguments.
- [STL Library](%5B10%5D%20STL%20Library/) — containers, iterators, and algorithms from the C++ Standard Library.
- [Recursion](%5B11%5D%20Recursion/) — recursive searching, sorting, combinations, permutations, and constraint problems.
- [OOPs](%5B12%5D%20OOPs/) — classes, constructors, inheritance, and polymorphism.
- [Linked List](%5B13%5D%20Linked%20List/) — list implementations, reversal, cycles, merging, and related problems.
- [Stacks](%5B14%5D%20Stacks/) and [Queues](%5B15%5D%20Queues/) — implementations and common applications, including sliding-window problems.
- [Binary Trees](%5B16%5D%20Binary%20Trees/) and [Binary Search Trees](%5B17%5D%20Binary%20Search%20Trees/) — traversals, views, construction, and tree operations.
- [Heaps](%5B18%5D%20Heaps/) — heap operations, priority queues, selection, and merging.
- [Hashmaps](%5B19%5D%20Hashmaps/) — maps and frequency counting.
- [Tries](%5B20%5D%20Tries/) — prefix lookup and phone-directory problems.
- [Backtracking](%5B21%5D%20Backtracking/) — exploring possible solutions with the rat-in-a-maze problem.
- [Dynamic Programming](%5B22%5D%20Dynamic%20Programming/) — memoization, tabulation, knapsack, sequence, and optimization problems.
- [Graph](%5B23%5D%20Graph/) — BFS, DFS, cycle detection, topological sorting, and shortest paths.
- [Bit Manipulation](%5B24%5D%20Bit%20Manipulation/) — bit counts, XOR-based problems, and bit operations.
- [Greedy Algorithms](%5B25%5D%20Greedy%20Algorithms/) — scheduling, Huffman encoding, and fractional knapsack.
